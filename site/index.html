Choose one persistent progress file for your slot:

Repentance+
rep+persistentgamedata1.dat
Repentance
rep_persistentgamedata1.dat
Rebirth / local save
persistentgamedata1.dat

The final digit, 1, 2 or 3 is the slot number. The + in rep+ is part of the filename. A file without a prefix may belong to different editions: its contents determine the version.

gamestate is not needed: it stores the current run. Do not select rep+gamestate, options.ini, log.txt, an archive or a folder.

Where can I find my save? ›

Use the folder for the edition you currently play. With Steam Cloud enabled, look in remote; otherwise, use the local game folder. If several folders exist, do not confuse an old Rebirth save with your Repentance+ progress.

You can also upload a backup, such as 20261015.rep+persistentgamedata1.dat, without renaming it. For current progress, choose the latest copy of the correct slot by its modification date. No accompanying gamestate file is needed. An empty slot is also valid; its file may not exist until the game creates it.
