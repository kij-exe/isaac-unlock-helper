Repentance / Repentance+ · любой слот

Только в браузере

Repentance и Repentance+ — тирлист, граф и статистика. Rebirth — статистика своего слота.

Нужен один файл общего прогресса выбранного слота:

Repentance+
rep+persistentgamedata1.dat
Repentance
rep_persistentgamedata1.dat
Rebirth / локальный сейв
persistentgamedata1.dat

В конце 1, 2 или 3 — номер слота. Знак + в rep+ — часть имени. Файл без префикса может принадлежать разным редакциям: сайт определит версию по содержимому.

gamestate не нужен: это текущий забег. Не выбирайте rep+gamestate, options.ini, log.txt, архив или папку.

Где найти нужный файл? ↗

Выберите папку той редакции, в которую играете сейчас. При включённом Steam Cloud смотрите папку remote, при выключенном — локальную папку игры. Если папок несколько, не путайте старый Rebirth-сейв с прогрессом Repentance+.

Можно загрузить резервную копию, например 20261015.rep+persistentgamedata1.dat, без переименования. Для актуального прогресса выбирайте свежую копию нужного слота по дате изменения. Загружать gamestate в пару к ней не нужно. Пустой слот — тоже допустимый файл; он может ещё не существовать, пока игра его не создала.
