# Проверка поставки

## Автоматические проверки

- `npm test`: 27 поведенческих проверок фронтенда. Парсер совпал с сохранёнными игрой checksum обоих исследованных файлов; подтверждены 3 отметки Азазеля, 1 испытание и 144 распознанных предмета первого слота, нулевой прогресс второго.
- Синтетический пустой файл генерируется тестом и не требует личных сохранений. Включение всех 637 секретов не меняет ни статистику, ни граф прогресса. Этот тест работает и в публичном CI, без `context/`.
- Проверены общая закрытая B для A/C, исчезновение выполненной B, AND/OR, неизвестные факты, завершённая альтернатива OR, прямое доказательство результата, фокус отдельного пути, отсутствие перекрытий всех вершин вертикальной раскладки, настоящие локальные PNG.
- `npm run validate:data`: 233 уникальные вершины, 188 записей тирлиста, 233 локальные иконки (199 PNG, 34 SVG); отсутствующих изображений, ссылок и циклов нет.
- `npm run build`: статическая сборка в `dist/`, личные сохранения и отчёты не копируются.
- Python-анализатор: все 22 существующие проверки сохранены и пройдены.

Три браузерных unit-теста с исходными файлами пропускаются, если `context/` отсутствует в публичном checkout; основные синтетические проверки парсера, пустого слота и графа выполняются без них.

## Стартовый экран и полное покрытие иконок

Стартовый экран показывает CSS-анимацию «сохранение → тирлист → граф открытия», понятный пример Mom’s Knife и компактную загрузку. У анимации есть пауза и статичная версия для prefers-reduced-motion; демонстрация не использует и не подменяет данные игрока.

Проверены SHA-256 всех 233 изображений и наличие локального файла для каждой вершины, PNG-сигнатуры и размеры; авторские SVG имеют отдельный статус designed. Упаковщик повторно использует проверенный кэш и сохраняет работающее изображение при ошибке обновления. Сопоставление Charged Key исправлено с335 на333 по уже имеющемуся игровому справочнику; отдельный тест подтверждает, что335 не открывает ключ, а333 влияет лишь на доступность и не доказывает прохождение испытания33.

## Редизайн интерфейса

Добавлены компактные спрайты вместо текстовых карточек, подсказки при наведении/фокусе, отдельная кнопка вики, светлая/тёмная темы и редакционные ряды S–F. Тема — единственное состояние, записываемое в localStorage.

Unit-тесты геометрии и обработчиков событий (без браузера) проверяют вертикальную раскладку без перекрытий, направление всех зависимостей, предел ширины, масштабирование вокруг курсора, непассивный wheel-обработчик с отменой прокрутки страницы, перетаскивание блока с обновлением обоих SVG-путей ребра, выбор вершины при pointer capture, перемещение фона, отмену перетаскивания, управление стрелками, восстановление анимации и освобождение обработчиков. Кнопка вписывания учитывает высоту полного графа.

Визуальная проверка **текущего редизайна не выполнена**: инструмент браузера отклонил доступ к локальному `http://127.0.0.1:4173/` по своей политике URL. Другие браузерные пути в обход отказа не применялись. Сборка и автоматические тесты пройдены.

## Историческая проверка браузера до редизайна

Следующие результаты относятся к предыдущей версии интерфейса, а не к новой раскладке. Тогда проверены в Chromium / Codex in-app browser:

- Инструкция загрузки, локальный выбор обоих `.dat`, обновление имени файла и состояния.
- Тирлист всех 188 записей, поиск Mom’s Knife, переключение статистики, собственные отметки и нулевой второй слот.
- Кнопка графа предмета, сложный путь Spindown Dice, полный граф, переключение основания графа, выбор другого анлока.
- Ручное подтверждение Magdalene не изменяет исходное сохранение или статистику, доступность по секрету показывается отдельно.
- Экраны 1280 × 900 и 390 × 844: горизонтального переполнения страницы нет; таблица отметок и граф прокручиваются внутри своих областей.
- Не обнаружены ошибки консоли и сломанные локальные изображения на проверенных экранах.
