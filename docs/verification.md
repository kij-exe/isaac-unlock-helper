# Проверка поставки

## Автоматические проверки

- `npm test`: 53 поведенческих проверок фронтенда. Парсер совпал с сохранёнными игрой checksum обоих исследованных файлов; подтверждены 3 отметки Азазеля, 1 испытание и 144 распознанных предмета первого слота, нулевой прогресс второго.
- Синтетический пустой файл генерируется тестом и не требует личных сохранений. Включение всех 637 секретов не меняет ни статистику, ни граф прогресса. Этот тест работает и в публичном CI, без `context/`.
- Проверены общая закрытая B для A/C, исчезновение выполненной B, AND/OR, неизвестные факты, завершённая альтернатива OR, прямое доказательство результата, фокус отдельного пути, отсутствие перекрытий всех вершин вертикальной раскладки, настоящие локальные PNG.
- `npm run validate:data`: 311 уникальных вершин, 189 записей тирлиста (188 из руководства и Dead God), 311 локальных иконок (209 PNG, 102 SVG); отсутствующих изображений, ссылок и циклов нет.
- `npm run build`: статическая сборка в `dist/`, личные сохранения и отчёты не копируются.
- Python-анализатор: все 24 проверки пройдены.

Три браузерных unit-теста с исходными файлами пропускаются, если `context/` отсутствует в публичном checkout; основные синтетические проверки парсера, пустого слота и графа выполняются без них.

## Новые сохранения и инструкции загрузки

Проверены все пять persistentgamedata-файлов из context: исходные Repentance, оба Repentance+ и Rebirth. JS/Python сравниваются по layout, фактическим массивам и checksum. Подтверждены новые checksum BD3B8630,04ADFD70,F9CACD7E. Проверено отсутствие изменения исходных файлов.

Синтетические пустые слоты всех трёх профилей сохраняют нулевой прогресс при включении всех секретов. Проверены все16 комбинаций online/offline-битов, повреждения, усечения, неизвестная схема, лишние данные. Dead God для Rep+ получает640 условий без изменения базового каталога и без зачёта секретов.

DOM-двойники выполняют настоящий обработчик выбора файла и рендер страниц: Rep+ открывает тирлист, Rebirth — свои66 отметок/20 испытаний с объяснением, gamestate показывает нужный persistentgamedata того же слота и сохраняет прежние данные. Ошибка первой загрузки раскрывает инструкцию. Это интеграционные проверки кода; они не заменяют визуальную проверку браузером.

Имена поддержанных файлов, знак+ как часть имени, выбор слота, Cloud/локальные папки, резервные копии с датой и неподходящие gamestate/options/log/архивы явно объяснены на главной странице. Источники и технические границы: [save-formats.md](save-formats.md).

## Связи всех 45 испытаний

Цель всех испытаний теперь ссылается на 45 общих вершин прохождения, каждая связана со своей вершиной доступа. Награды и перечень условий Dead God повторно используют те же вершины. Включение секретов на пустом слоте по-прежнему не меняет граф прогресса. Проверены доступное, но не пройденное испытание, независимое доказательство завершения при неизвестной истории доступа, общий путь Solar System → прохождение → Rune of Perthro / все испытания, сценарий 44 из 45 и восстановление всех шагов переключателем выполненных. Проверены все 45 наборов зависимостей по закреплённому игровому challenges.xml, отсутствие циклов и детерминированность генератора. Визуальная проверка по-прежнему ограничена отказом браузерного инструмента, указанным ниже.

## Skill Issue Tracker и Dead God

Бренд заменён на Skill Issue Tracker. Локальная прозрачная мемная GIF постоянно танцует в логотипе без наведения и таймера; favicon статичный. Источник, авторы и SHA-256 сохранены в assets/brand/manifest.json. По явному запросу пользователя логотип всегда анимирован; настройка reduced motion продолжает отключать остальные CSS-анимации сайта.

Dead God — одна карточка над S–F. Тесты подтверждают точное покрытие 1–636 без 637/Rep+,717 уникальных required collectible ID с включением квестовых частей и 474 и исключением hidden/неопределённых ID. Секрет 637 и даже все 637 флагов на пустом слоте не подтверждают выполнение цели. Полностью подтверждённые игровые факты вместе с явными ручными фактами дают выполненную цель при нулевых секретах; отсутствие DELETE THIS, любого нужного предмета либо обязательного ручного факта снова блокирует подтверждение. Проверены неизвестные collection bytes и отклонение недопустимых ID.

## Стартовый экран и полное покрытие иконок

Стартовый экран показывает CSS-анимацию «сохранение → тирлист → граф открытия», понятный пример Mom’s Knife и компактную загрузку. У анимации есть пауза и статичная версия для prefers-reduced-motion; демонстрация не использует и не подменяет данные игрока.

Проверены SHA-256 всех 233 изображений и наличие локального файла для каждой вершины, PNG-сигнатуры и размеры; авторские SVG имеют отдельный статус designed. Упаковщик повторно использует проверенный кэш и сохраняет работающее изображение при ошибке обновления. Сопоставление Charged Key исправлено с 335 на 333 по уже имеющемуся игровому справочнику; отдельный тест подтверждает, что 335 не открывает ключ, а 333 влияет лишь на доступность и не доказывает прохождение испытания 33.

## Редизайн интерфейса

Добавлены компактные спрайты вместо текстовых карточек, подсказки при наведении/фокусе, отдельная кнопка вики, светлая/тёмная темы и редакционные ряды S–F. Тема и язык — единственные настройки, записываемые в localStorage.

Unit-тесты геометрии и обработчиков событий (без браузера) проверяют вертикальную раскладку без перекрытий, направление всех зависимостей, предел ширины, масштабирование вокруг курсора, непассивный wheel-обработчик с отменой прокрутки страницы, перетаскивание блока с обновлением обоих SVG-путей ребра, выбор вершины при pointer capture, перемещение фона, отмену перетаскивания, управление стрелками, восстановление анимации и освобождение обработчиков. Кнопка вписывания учитывает высоту полного графа.

Визуальная проверка **текущего редизайна не выполнена**: инструмент браузера отклонил доступ к локальному `http://127.0.0.1:4173/` по своей политике URL. Другие браузерные пути в обход отказа не применялись. Сборка и автоматические тесты пройдены.

## Границы проверки

Это проверка состояния файлов и приложения, а не доказательство исторического происхождения прогресса. Состояние Steam-аккаунта не читалось.
