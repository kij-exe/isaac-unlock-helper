## Verification limits

This is a check of the state of the files and the application, not proof of the historical origin of progress. The Steam account state was not read. Guide and wiki conditions were not verified by running each scenario in the game; unsaved or ambiguous actions require manual confirmation. Repentance+ is supported by a separate profile; Rebirth has its own statistics, to which the Repentance graph requirements do not apply. Afterbirth/Afterbirth+ and unverified schemas are not supported yet. The GitHub Pages workflow is prepared, but remote publishing was not run: the user allowed only `git status` and `git diff`.
