# Локализация RU / EN

Переключатель в шапке работает до и после загрузки сохранения. По умолчанию выбран русский; выбранный язык хранится в `localStorage` под ключом `atlas-language`. Настройка темы независима. При недоступном хранилище язык переключается в текущей вкладке.

`site/js/i18n.js` содержит переводчик и локализацию представления. `site/js/locales/en.js` — английский словарь, где исходные русские фразы служат ключами. Стандартные подписи с числами, именами персонажей и предметов переводятся параметризованными правилами. Статические элементы переводятся без замены DOM, с восстановлением исходных текстов при возврате к RU. Динамические HTML-шаблоны приложения используют тег `html`, текстовые статусы — `i18n.text`.

Каталог `unlocks.json` остаётся каноническим. Для английского интерфейса создаётся копия только с переводом полей представления: `name`, `label`, `description`, `reason`, `sourceNote`. Профиль редакции применяется перед переводом, поэтому дополнительные условия Repentance+ также локализованы. IDs, ключи ручного подтверждения, числа, условия, доказательства, ссылки, исходный сейв и экспорт статистики не меняются. Названия предметов и персонажей сохранены в оригинале. Поиск учитывает русские и английские описания независимо от выбранного языка.

При добавлении анлока или нового текста интерфейса:

1. Добавьте исходный русский текст в каталог или шаблон.
2. Для нестандартной фразы добавьте точный английский перевод в `site/js/locales/en.js`. Для повторяющейся структуры используйте параметризованное правило в `i18n.js`; не переводите произвольные IDs или пользовательский ввод.
3. Выполните `npm test`, `npm run validate:data`, `npm run build`.

`tests/i18n.test.mjs` проверяет покрытие всех отображаемых полей каталога обоих профилей, неизменность логики и связей, хранение настройки и обратный перевод DOM. Интеграционные проверки в `tests/upload-flow.test.mjs` проверяют настоящий обработчик переключения языка, загрузку и ошибки, страницы, выбранную вершину, ручные подтверждения и масштаб. Тесты не требуют стороннего сервиса перевода; сайт не отправляет туда данные игрока.
